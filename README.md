# Avinash & Mahak — Wedding Invitation Website

This is the corrected, self-contained version of the wedding website. All four original couple photos and the uploaded Sajna MP3 are embedded directly inside `index.html`. **You only need to upload `index.html` to publish it**; there is no separate assets folder to forget.

## Publish with GitHub Pages
1. Download and extract this ZIP.
2. Create/open your GitHub repository.
3. Upload `index.html` to the repository root (not inside another folder).
4. Open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Open the published `github.io` link.

## Photos and music
- Original uploaded couple photos are embedded as provided; no face edits or AI retouching.
- The uploaded `Sajna` MP3 is embedded in the page.
- On the first screen, tap **Open Invitation** to start music. If the browser blocks the first attempt, tap **Play Music** once. This is a mobile-browser restriction, not a missing audio file.
- The floating music button toggles play/pause.
